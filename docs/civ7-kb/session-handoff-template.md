# Session handoff template

Copy the fenced block into the next session's notes or a new campaign-specific Markdown file. Do not overwrite the conceded run's history. A short accurate record is better than a giant stale snapshot.

## Good handoff habits

- Distinguish a civic being **recommended**, **selected**, **completed**, and its card being **equipped**.
- Record whether an expensive purchase was actually made. "Affordable" and "user bought" are different evidence.
- Include a landmark or screenshot reference with coordinates; don't invent direction labels.
- Carry source labels into the record. Don't promote a conjecture to fact through repeated summarization.
- If a new live warning contradicts an earlier strategy, put it first rather than beneath a long production list.
- Do not include bearer tokens, service credentials, local authentication configuration or unrelated repository details.
