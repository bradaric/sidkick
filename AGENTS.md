# Project guidance

## Civilization VII gameplay advice

When the user asks for Civilization VII gameplay strategy, campaign analysis or
replay planning, first read `docs/civ7-kb/SKILL.md` and follow its relevant
references. Load only the reference pages needed for the question, not the whole
knowledge base on every request.

For live turn-by-turn play, also read `docs/civ7-kb/turn-flow.md` and follow its
briefing, remaining-task and readiness workflow without waiting for reminders.

Treat recorded campaign states and recommendations as historical, not current
game state. Refresh relevant read-only evidence before giving live advice.

These coaching instructions apply to gameplay questions only. For Sidkick
software-development tasks, use the repository documentation and code; do not
apply the campaign's gameplay preferences as development instructions.
